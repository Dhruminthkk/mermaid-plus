Chapter 9

Reference

Every directive and every key, in one place. All of them are Mermaid comments, so a file that uses them still renders in GitHub, Notion and stock mermaid.js — the extensions cost you no portability.

Directives

DirectiveEffect
theme <id>Pin a theme. <family>-light or -dark for clean, slate, blueprint, notebook, vivid, contrast, paper, mono, terminal, ocean
node <id> archetype=<a>service, database, queue, storage, user, external, process, decision, note, default
node <id> icon=<ref>general:, tech:, aws:, gcp:, azure:, k8s: plus a name — or none
node <id> note="…"Prose shown when a reader selects it. Works on edge and group too
node <id> <key>="…"Any other attribute shows as metadata — owner, team, sla, whatever you need
edge <a>-><b> semantics=<s>flow, async, dependency, association, inheritance, composition, bidirectional
edge <a>-><b> flowForce the travelling highlight on one edge. flow=false takes it off
group <id> collapsedStart a subgraph collapsed
layout direction=<d>DOWN, RIGHT, UP, LEFT — or TB, LR, BT, RL
layout edgeLabels=besideMove edge labels off the line. They sit on it by default
layout flow=<all|auto|none>Which edges carry a travelling highlight
layout motion=offStill this diagram entirely
step <n> focus=<ids> title="…" note="…"One step of a walkthrough. A group name focuses everything inside it; no focus is a title card

Values may be quoted, so a note can be a whole sentence. Several settings can share one layout line, or sit on separate lines — they are merged.

Keyboard

KeyDoes
⌘K / Ctrl KSearch examples, themes and actions
FFull-bleed. Typing an f in the editor still means the letter f
EscClear the selection, leave full-bleed, end a walkthrough, close a menu
← → ↑ ↓Follow connections — or advance a walkthrough while one is running
EnterExpand the selected collapsed group

URL parameters

ParameterDoes
?ex=flowchart:0Open an example by kind and index
?theme=slate-darkOpen with a theme selected
?step=3Start a walkthrough at a given step
?galleryThe example gallery instead of the editor

Diagram kinds

Drawn by the custom engine: flowchart, class, state, entity relationship, mindmap, requirement, C4. These get real layout, archetypes, icons, collapsing, focus and the draw.io export.

Drawn by mermaid.js in the same theme: sequence, gantt, pie, timeline, journey, git graph, quadrant, XY chart, sankey, block, kanban, packet, architecture. They match the rest of your document, and new kinds work the day the dependency is updated.
