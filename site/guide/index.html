Guide

How to use Mermaid Plus

It reads the Mermaid you already write. This guide is about everything it does with it afterwards — nine chapters, about twenty minutes end to end.

What it adds to Mermaid

Same files, same syntax. Every extension below is written as a %% comment, so a file that uses them still renders in GitHub, Notion and stock mermaid.js — you are not trading portability for any of it.

Stock mermaid.jsHere
Layout Dagre. Subgraphs sit behind their contents ELK layered. Subgraphs are containers the layout understands, edges route orthogonally with space reserved for their labels, and an edge can target a whole group
Node appearance The bracket shape you typed, in the theme's colour The shape, colour and icon are inferred from the label — a cylinder for a database, a dashed border for anything external, and about ninety real technology marks
Big diagrams Everything is drawn, every time Collapse a subgraph to one node and its crossing edges bundle with a count; focus by hop radius; find by name; semantic zoom; only what is on screen is drawn
Reading one Read the source Click any component for what it depends on, what depends on it, and the note the author wrote. Arrow keys follow connections
Presenting one A picture Numbered steps frame the diagram a part at a time with a note each. One key clears every piece of interface
Themes Five, plus theme variables Twenty, light and dark, each contrast-checked by a test. Edit the tokens and export the result as JSON
Export SVG and PNG Those, plus PDF, a standalone interactive HTML page, and a draw.io / Lucid file that is still a model rather than a picture
Where it runs A library you wire up, or a hosted editor Entirely in your browser. No account, and nothing is uploaded — which is what the hosted editors ask you to accept

Nothing is given up. Thirteen diagram kinds — sequence, gantt, pie, journey, git graph and the rest — are still drawn by mermaid.js itself, wearing the same theme as everything else, so a new upstream diagram kind works the day the dependency is updated.
